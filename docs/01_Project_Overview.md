# 1. Introduction

## Project Introduction

The **Tara Guest House Management System** is a modern hotel website and administration platform developed for **Tara Guest House, Sauraha, Nepal**.

The goal of this project is to replace the client's existing website with a professional, secure, responsive, and scalable web application that improves customer experience while providing powerful management tools for hotel staff.

Unlike the previous website, the new platform will include an integrated Content Management System (CMS), reservation management, customer reviews, gallery management, room management, booking workflow, invoice generation, and payment verification.

The project is being developed by **fero.dev** as its first commercial software project.

# 10. Project Success Criteria

The project will be considered successful if:

- The website is fully responsive across desktop, tablet, and mobile devices.
- Customers can easily browse rooms, activities, galleries, and services.
- Reservations can be submitted and managed efficiently by administrators.
- The CMS enables the hotel owner to update content without editing source code.
- Security best practices are implemented throughout the application.
- The system is stable, maintainable, and production-ready.
